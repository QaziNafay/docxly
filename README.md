# Docxly

**Making Formatting Easy!**

Docxly is a small set of focused tools that make formatting in Microsoft Word quick
and boring, so you can get back to the work that matters. Each tool does one job
well, and nothing else. No AI, no sign up, and your files are never stored.

## Tools

- **Docxly Bold**: bold the headings in a Word document.
  https://siliconmystic.com/docxly/docxly-bold/
- **Docxly Wrap**: fix stretched justified text.
  https://siliconmystic.com/docxly/wrap-fix-justified-text/

## Product philosophy

Formatting should not be a chore. We build small, predictable tools that fix one
annoying thing at a time. Simple, honest, and free.
